# RoboSim

محاكي روبوتات يعمل في المتصفح (الهدف: Chromebook). مشروع واحد بملف `package.json` واحد.

## الهيكل (مجلدان فقط)
```
backend/     محرك المحاكاة: العقود والبروتوكول، Rapier، الساعة، الذاكرة المشتركة، sim.worker.ts
             motors.ts (PID ومحرك بحد عزم)، robot.ts (مواصفات الروبوت وبناؤه والقيادة التفاضلية)
frontend/    الصفحة: index.html + main.ts + public/_headers
  render/    الرسم: scene-view.ts (Three.js)، interpolator.ts (استيفاء اللقطات)، quality.ts (جودة تلقائية)
```
قاعدة الاعتماد: `frontend` يستورد من `backend`، و`backend` لا يستورد من `frontend`.

**خارج المشروع:** أي Cloudflare Workers أو قاعدة SQL (مثل D1) أو خادم لاحق تُبنى منفصلة
خارج هذين المجلدين، ولا تدخل في هذا المشروع الآن.

## التشغيل المحلي
```bash
npm install
npm run dev        # http://localhost:5173
npm test
```
افتح الصفحة: يجب أن تظهر ✔ أمام `crossOriginIsolated` و`WebGL2`، وتسقط 50 صندوقاً و20 كرة في مشهد ثلاثي الأبعاد وتستقر.

**الكاميرا:** سحب = تدوير، عجلة = تقريب، سحب يمين أو Shift = تحريك. انقر على جسم لتحديده (يصفرّ) ثم «تتبع المحدد».
**الجودة:** تلقائي افتراضياً (تنخفض عند البطء وترتفع ببطء بعد استقرار 8 ثوانٍ)، أو ثبّتها يدوياً من القائمة.
**التصحيح:** `window.__robosim` في وحدة التحكم.

## النشر على Cloudflare
**الطريقة 1: من الطرفية**
```bash
npm run cf:preview   # معاينة محلية بنفس ترويسات الإنتاج
npm run deploy       # يطلب تسجيل الدخول أول مرة
```
**الطريقة 2: ربط GitHub** (Workers & Pages ← Import a repository)
- Build command: `npm install && npm run build`
- Deploy command: `npx wrangler deploy`
- متغير بيئة: `NODE_VERSION = 20`

الترويسات `COOP/COEP` مطلوبة لـSharedArrayBuffer وتأتي من `frontend/public/_headers`.
تنبيه COEP: لا تحمّل صوراً أو سكربتات من نطاقات خارجية؛ ضع كل الأصول على نفس النطاق.

## المرحلة 3: الروبوت والمحركات
**القيادة:** W/S أو ↑/↓ أمام/خلف، A/D أو ←/→ دوران، Space كبح، Shift أسرع.
**الاتجاهات:** +X أمام، +Y أعلى، +Z يمين. الدوران الموجب (yaw) = لليسار.

**المحرك:** تحكم سرعة بـPID، العزم محدود بـ`maxTorque`، ويتناقص خطياً حتى صفر عند `maxVelocity` (سرعة بلا حمل).
تُحسب العزوم قبل كل خطوة فيزياء (240Hz). عند رفع `kp` على عجلة خفيفة قد يصير التحكم غير مستقر؛ القاعدة: `kp * dt < 2 * J` حيث J عطالة العجلة.

**تغيير المواصفات:** زر «تنزيل المواصفات» يعطيك ملف JSON، عدّله ثم «تحميل مواصفات». الحقول غير المذكورة تأخذ القيم الافتراضية،
والحقل المكتوب بخطأ إملائي يُرفض برسالة واضحة. مثال مختصر:
```json
{ "name": "Heavy", "chassis": { "mass": 3, "color": "#ef4444" }, "motor": { "maxTorque": 0.6 } }
```
**حدود معروفة:** حالة المحركات (تكامل PID) لا تدخل في snapshot/restore بعد؛ تُضاف مع نظام الوحدات (المرحلة 5).
